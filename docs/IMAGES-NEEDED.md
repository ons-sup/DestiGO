## Placeholder Strategy

For any missing image, the components render a **neutral gradient placeholder** with the item name as text (see `image-placeholder` CSS class in both detail components). This ensures no broken `<img>` tags appear in production.

The placeholder uses CSS custom properties:
```css
--placeholder-start: #e8e8e8;
--placeholder-end: #d0d0d0;
--placeholder-bg: linear-gradient(135deg, var(--placeholder-start), var(--placeholder-end));
--placeholder-text: #888;
```

These can be customized in `src/styles.css` or component styles.
